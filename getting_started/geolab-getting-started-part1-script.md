# GeoLab: Get Running (Part 1 of 2) — Video Script

**Runtime:** ~10:00
**Format:** Screen-capture (browser + JupyterLab) + narration, lower-thirds per stage, on-screen checklists/warning cards
**Audience:** New GeoLab users doing their first real session — from account login through running their first notebook cell
**Covers:** Accessing GeoLab, Launching Your Server, Navigating GeoLab, Using the Terminal, Working with Notebooks
**Sources:**
1. [Accessing GeoLab](https://docs.earthscope.org/geolab/getting-started/access)
2. [Launching your Server](https://docs.earthscope.org/geolab/getting-started/server-launch)
3. [Navigating GeoLab](https://docs.earthscope.org/geolab/getting-started/basic-navigation)
4. [Using the Terminal in GeoLab](https://docs.earthscope.org/geolab/getting-started/geolab-terminal)
5. [Working with Notebooks](https://docs.earthscope.org/geolab/getting-started/notebooks)

**Series context:** Part 1 of 2. Part 2, "Work Like a Pro," covers git, storage, quotas, and examples/tutorials. This replaces the single combined `geolab-getting-started-tour-script.md` with two full-length videos, giving each stage roughly double the demo time.

### Production notes
- Record the server-spawn progress bar (4:00–4:35) at real speed once, then speed-ramp in editing — consistent with how long waits are handled elsewhere in this repo's scripts.
- Use a disposable/demo GeoLab account throughout. The `whoami`/prompt segment at 7:05–7:45 shows the account's unique ID string on screen — confirm it isn't tied to any real personal identifier before publishing.
- The out-of-order execution demo (8:55–9:35) is the single most valuable teaching moment in this video for a true beginner — don't cut it short in editing even if time is tight elsewhere.
- Verify current environment-dropdown labels, server-size tiers, and the exact auto-stop timing (60 minutes) against the live GeoLab UI before final recording, since these are the details most likely to have changed since this script was written: https://docs.earthscope.org/geolab/getting-started/server-launch
- Part 2 opens with its own short recap for anyone who arrives without having watched this one — no need to re-explain these five stages here beyond what's already in this script.
