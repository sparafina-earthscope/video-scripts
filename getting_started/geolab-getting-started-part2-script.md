# GeoLab: Work Like a Pro (Part 2 of 2) — Video Script

**Runtime:** ~10:00
**Format:** Screen-capture (browser + JupyterLab + terminal) + narration, lower-thirds per stage, on-screen diagrams/worked examples
**Audience:** GeoLab users who already have a server running and a notebook working — ready to bring in their own code, understand their storage, and manage their compute quota
**Covers:** Using Git with GeoLab, File Systems and Data Storage, Resource Quotas, Examples and Tutorials
**Sources:**
1. [Using Git with GeoLab](https://docs.earthscope.org/geolab/getting-started/using-git)
2. [File Systems and Data Storage](https://docs.earthscope.org/geolab/getting-started/user-storage)
3. [Resource Quotas](https://docs.earthscope.org/geolab/getting-started/quotas)
4. [Examples and Tutorials](https://docs.earthscope.org/geolab/getting-started/examples-tutorials)

**Series context:** Part 2 of 2. Part 1, "Get Running," covers access, server launch, navigation, the terminal, and notebooks — watch that one first if you haven't logged into GeoLab yet. This video assumes a working session already open.

### Production notes
- Use a disposable/demo GitHub account and a throwaway SSH key pair for the 2:15–3:15 segment; revoke the key immediately after recording. Never let a real, still-usable key or token stay visible past the recording session.
- The worked compute-hour math (6:25–7:10) is the section viewers are most likely to screenshot or pause on — keep the on-screen numbers large and legible, held on screen slightly longer than the VO strictly requires.
- Confirm the current `du -sh`/`$SCRATCH_BUCKET` behavior, the 50GB home-directory limit, and the us-east-2 region recommendation against the live docs before final recording, since infrastructure specifics like these are the most likely to drift: https://docs.earthscope.org/geolab/getting-started/user-storage and https://docs.earthscope.org/geolab/getting-started/quotas
- If publishing standalone rather than as part 2 of a pair, expand the 0:40–0:55 roadmap beat into a fuller ~30–45s recap of part 1's five stages, since this script otherwise assumes that context.
