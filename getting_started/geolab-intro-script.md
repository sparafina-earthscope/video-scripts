# Introducing GeoLab — Video Script

**Runtime:** ~5:00
**Format:** Screen-capture + narration (voice-over), light motion graphics for titles/lower-thirds
**Audience:** Geophysics educators, students, and researchers new to EarthScope's cloud tools

---

| TIME | VISUAL | AUDIO (VO / ON-SCREEN TEXT) |
|---|---|---|
| 0:00–0:20 | Cold open: quick montage — a seismic waveform scrolling, a GNSS station on a hillside, a crowded laptop desktop with failed package installs, a student staring at a spinning download progress bar. Cut to EarthScope logo. | **VO:** "Every geophysicist knows this problem: the data is enormous, the software setup takes half a lab session, and by the time everything's installed, the class — or the deadline — is over. What if you could skip all that and start analyzing data in your browser, in seconds?" |
| 0:20–0:35 | Title card: **"Introducing GeoLab"** with EarthScope wordmark. | **VO:** "This is GeoLab — EarthScope's free, browser-based notebook hub for geophysical research and teaching." |
| 0:35–1:05 | Screen capture: browser opens to earthscope.org/data/geolab. Slow pan/highlight of the GeoLab landing page description. | **VO:** "GeoLab is a JupyterHub built for the global community of geophysical researchers, educators, and engineers. It runs right next to EarthScope's NSF NGF data archive, so you can explore seismic, GNSS, and strain data without ever downloading it — and it comes with Jupyter notebooks and RStudio ready to go, no installation required." |
| 1:05–1:15 | Lower third: **"Step 1 — Create a free EarthScope account"** | **VO:** "Getting started takes two steps. First, you need an EarthScope account." |
| 1:15–1:55 | Screen capture: navigate to earthscope.org, click the account/login icon in the header, land on the account page (earthscope.org/user). Show sign-up form being filled with a placeholder name/email, then account confirmation screen. | **VO:** "Go to earthscope.org and click the account icon in the top menu — or head straight to earthscope.org/user. Sign up with your email, verify your address, and you're done. This single account is your key to every EarthScope service: GeoLab, authenticated data access, the community forum — all of it, and it's completely free." |
| 1:55–2:05 | Lower third: **"Step 2 — Launch GeoLab"** | **VO:** "Now that you've got an account, let's launch GeoLab." |
| 2:05–2:45 | Screen capture: back on earthscope.org/data/geolab, click "Launch GeoLab." Redirect to login screen, sign in. Show the server "spawn" screen with environment options, then a live JupyterLab interface loading with a file browser and an example notebook open. | **VO:** "From the GeoLab page, click Launch, and sign in with the account you just created. Choose your environment — GeoLab gives you a standard notebook server, and you can request more memory or CPU if your workflow needs it. Within moments, you're in a full JupyterLab environment, already connected to shared data and pre-loaded example notebooks from the GeoLab Learning Hub." |
| 2:45–2:55 | Title card: **"Why GeoLab? — For the Classroom"** | **VO:** "So why does this matter — starting with teaching." |
| 2:55–3:45 | Screen capture / mockup: instructor's notebook with markdown explanations, code cells, and a plot of earthquake waveforms; cut to a "Share" or GitHub link; cut to a grid of student laptops all showing the same notebook running identically. | **VO:** "For instructors, GeoLab removes the biggest barrier to hands-on data science: environment setup. Build a notebook once — with the data, the code, and the explanation together — and every student opens the exact same working environment, on any laptop, from a browser tab. No 'it works on my machine.' No lost class time troubleshooting installs. Just students doing real geophysics from minute one." |
| 3:45–3:55 | Title card: **"Why GeoLab? — For Research"** | **VO:** "For researchers, the benefits go further." |
| 3:55–4:30 | Screen capture: notebook running a larger processing job against cloud-hosted data; a second pane showing scalable compute options; a glimpse of the GeoLab Learning Hub GitHub repo and the community forum page. | **VO:** "Because GeoLab sits right alongside EarthScope's cloud data archive, you can prototype a workflow on a small slice of data, then scale it up to run against the full archive — without ever moving files to your own machine. Your notebooks are reproducible and shareable, so collaborators, reviewers, or your future self can rerun your exact analysis. And when you need help, the GeoLab Learning Hub and community forum connect you to example notebooks and other researchers solving similar problems." |
| 4:30–4:50 | Return to GeoLab landing page; highlight "Launch GeoLab" button once more. On-screen text: **"Free. Browser-based. No installation."** | **VO:** "GeoLab is free to use, runs entirely in your browser, and puts you next to the data instead of making you chase it. Whether you're teaching your first seismology lab or scaling up a continent-wide GNSS analysis, GeoLab is built to get you there faster." |
| 4:50–5:00 | End card: EarthScope logo, URLs on screen: **earthscope.org/user** (create an account) and **earthscope.org/data/geolab** (launch GeoLab). | **VO:** "Create your free account at earthscope.org, launch GeoLab, and start exploring. We'll see you in the notebook." |
