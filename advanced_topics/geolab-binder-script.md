# GeoLab Binder: Build Images Without Docker — Video Script

**Runtime:** ~6:50 (6–7 min target)
**Format:** Screen-capture (GitHub + browser + GeoLab UI) + narration, light motion graphics for titles/lower-thirds/code call-outs
**Audience:** Researchers and educators who want a shareable, reproducible GeoLab environment but don't want to install or learn Docker
**Source:** [docs.earthscope.org/geolab/advanced-topics/environments/binder-for-images](https://docs.earthscope.org/geolab/advanced-topics/environments/binder-for-images)
**Series context:** Follows "Creating Temporary Environments in GeoLab" and "Building Custom Images for GeoLab" — this video is the no-Docker alternative to the last one

### Production notes
- Use a disposable, throwaway GitHub repo for all screen capture; if it's left public afterward, strip any personal info from commit author fields before publishing.
- The "first build takes several minutes" wait (4:30–5:10) should be recorded in real time once and speed-ramped in editing, consistent with the standard set in the two earlier videos in this series — don't cut around it.
- Confirm the exact wording of the environment-selector option ("Build your own image") and the field label for the repo URL against the live GeoLab UI before final recording, since UI copy can change: https://docs.earthscope.org/geolab/advanced-topics/environments/binder-for-images
- If publishing standalone rather than as part of the series, add a short (~15s) recap of what `environment.yml`/`apt.txt`/`requirements.txt` do near 2:05, since this script assumes that context from the custom-images video.
