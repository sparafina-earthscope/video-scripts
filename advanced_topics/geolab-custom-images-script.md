# Building Custom Images for GeoLab — Video Script

**Runtime:** ~6:55 (6–7 min target)
**Format:** Screen-capture (terminal + Docker Desktop + JupyterLab + browser) + narration, light motion graphics for titles/lower-thirds/code call-outs
**Audience:** Researchers and educators who've outgrown temporary environments — need system-level packages, or a reproducible stack for a whole team or course
**Source:** [docs.earthscope.org/geolab/advanced-topics/environments/building-custom-images](https://docs.earthscope.org/geolab/advanced-topics/environments/building-custom-images)
**Prerequisite viewing:** "Creating Temporary Environments in GeoLab" (this series) — this video assumes that one

If you're building on a Mac with Apple Silicon, your machine uses a different chip architecture by default — so this build needs the platform flag, dash dash platform linux slash amd64, and your registry username baked into the tag now too. Second: a package's install name and its import name aren't always the same — scikit-learn installs under one name, imports under another. Before you build, check conda search dash c conda-forge, or python dash m pip index versions, to confirm the name you're adding is the one that actually exists." |

### Production notes
- Record the two `docker build` segments at real speed once, then speed-ramp in editing (per the "4x" notes) — matches the standard set in the temporary-environments video; don't fake either build with a cut.
- Use a disposable Docker Hub / GHCR account and a throwaway image name for all screen capture; scrub any personal registry username from earlier takes if you re-record with a different account.
- The `--platform linux/amd64` beat (4:25–4:55) is the single most likely point of confusion — consider a follow-up short/FAQ clip if comments show people still hitting architecture mismatches after this video.
- Verify exact commands, file names, and the "Other" environment field in the Start-server UI against the live docs before final recording: https://docs.earthscope.org/geolab/advanced-topics/environments/building-custom-images
- This script assumes viewers have already seen the temporary-environments video; if publishing standalone, add ~20–30s near 1:15 briefly defining `environment.yml` for viewers arriving cold.
